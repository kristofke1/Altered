# Abelena

## Overview
Abelena is an archipelago within [[Asgartha]], located along the [[Sundström Route]] maritime channel.

## Port of Gusta
The archipelago contains the port of [[Gusta]], which serves as an obligatory stopover point for ships navigating the [[Sundström Route]] between [[Suspira]] and [[Arkaster]].

## Relationships
- **[[Asgartha]]**: Nation containing the archipelago
- **[[Gusta]]**: Port located on the archipelago
- **[[Sundström Route]]**: Maritime route passing by the archipelago
- **[[Undersea]]**: Sea in which the archipelago is located
